# DocDiff (文档差异标红工具) 软件设计说明书

## 1. 系统概述

### 1.1 软件名称
**DocDiff** (Document Differential Renderer)

### 1.2 背景与目标
在企业办公、合同审查及法规审计场景中，对比两个 `.docx` 文档并准确标注差异是高频核心需求。商业比对软件通常收费昂贵且存在数据隐私外泄隐患。

DocDiff 是一套**完全开源、本地运行、符合合规审计**的文档比对解决方案。能够自动比对新旧 `.docx` 文档，将新增修改内容标记为**红色粗体**，删除内容标记为**红色删除线**，并导出可视化变更文档。

---

## 2. 整体架构与模块设计

系统采用分层与模块化架构设计，分为**输入与交互层 (GUI/CLI)**、**异步任务调度层**、**差异计算与结构对齐层**及**文档渲染导出层**。

```text
+-------------------------------------------------------------------+
|               用户交互层 (PySide6 GUI / CLI 命令行)               |
|            - 支持文件路径输入、拖拽 (Drag & Drop) 及参数配置     |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                     异步任务调度层 (QThread Worker)               |
|              - 防止大文件比对卡顿，提供进度与日志回调            |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                  结构对齐与差异引擎 (DocDiff Core)                |
|  1. ParagraphAligner: 基于 LCS 算法做段落级全局对齐 (消除错位)   |
|  2. TextDiffEngine: 基于 SequenceMatcher 做字符级差异计算         |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                   文档渲染与导出层 (Docx Renderer)                |
|      - 基于 python-docx 保持原有段落样式                           |
|      - 注入红色高亮 (#FF0000) 与删除线 (Strike-through)            |
+-------------------------------------------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|                   目标文件导出 (*_tracked.docx)                   |
+-------------------------------------------------------------------+
```

## 3. 核心算法与逻辑设计

### 3.1 段落级 LCS 全局结构对齐 (`ParagraphAligner`)
针对在旧文档中间插入或删除段落的情况，传统基于索引对比的方法会导致后文全部错位。
本系统在 `aligner.py` 中引入**最长公共子序列 (LCS)** 及基于相似度阈值的最佳匹配机制：
- 对齐状态 `equal` / `replace`（相似度 `> 0.4`）：交由字符级引擎计算内部差异。
- 新增状态 `insert`：认定为纯新增段落，全段标记为红色。
- 删除状态 `delete`：认定为纯删除段落，全段标记为红色删除线。

### 3.2 字符/词级差异计算 (`DocDiffEngine`)
对匹配到的段落对，使用 `difflib.SequenceMatcher` 计算 Text Chunk 差异：
- **`equal` 片段**：保持原文本与段落样式。
- **`insert` 片段**：设为 `RGBColor(255, 0, 0)`（纯红）+ Bold。
- **`delete` 片段**：设为 `RGBColor(255, 0, 0)`（纯红）+ Strike-through。

## 4. 技术栈与环境管理

### 4.1 技术选型
- **核心语言**：Python 3.10+
- **环境与依赖管理**：`uv` (采用清华镜像源 `https://pypi.tuna.tsinghua.edu.cn/simple`)
- **GUI 框架**：PySide6 (Qt for Python)
- **Word 文档处理库**：`python-docx`
- **解析库**：`lxml`

### 4.2 环境搭建与运行
使用 `uv` 管理虚拟环境：
```powershell
# 安装依赖
uv sync

# 运行 GUI 界面
uv run python main.py

# 运行引擎测试
uv run python -m tests.test_diff
```
